1.1 زبان‌های قابل تشخیص  [Fact]
    (a) Bash — زبان میزبان. شِبانگ `#!/usr/bin/env bash`، حالت سخت‌گیرانه
        `set -euo pipefail`.
    (b) Python 3 — در دو نقش کاملاً متمایز که تفکیک آن‌ها برای فهم فایل حیاتی است:
          • Python «زمان نصب» (install-time): داخل `python3 <<'PYEOF' ... PYEOF`
            اجرا می‌شود، فایل‌های JSON/JS پروژه را می‌خواند و بازنویسی می‌کند و
            بعد از پایان اسکریپت دیگر وجود ندارد.
          • Python «زمان اجرا» (runtime): داخل `write_utf8 <path> <<'EOF' ... EOF`
            فقط به‌عنوان متن نوشته می‌شود، روی دیسک می‌نشیند و بعداً توسط Frappe
            اجرا می‌شود.
    (c) JavaScript — سه دسته: `frappe.query_reports[...]` برای فیلتر/دکمهٔ گزارش،
        `frappe.ui.form.on(...)` برای فرم، `frappe.listview_settings[...]` برای لیست.
    (d) JSON — تعریف Report، Print Format، Workspace، fixture ترجمه، DocType.
    (e) SQL — لهجهٔ MariaDB/MySQL: بک‌تیک برای نام جدول (`` `tabTrade Case` ``)،
        `ifnull`, `nullif`, `date_format`, `timestampdiff`, `if(...)`.
    (f) Jinja2 + HTML — بدنهٔ چهار Print Format راست‌به‌چپ.

■ fa_digits(value) -> str
  None → ""، سپس join رقم‌به‌رقم با `_FA_DIGITS[int(char)] if char.isdigit()`.
  مرزی: چون ارقام فارسی هم `isdigit()` True دارند و `int("۵")==5` است، تابع
  idempotent است. [Inference]

■ normalize_persian(value) -> str   ← حیاتی
  ترتیب دقیق عملیات:
      1) None → ""
      2) حذف تک‌تک ۶ کاراکتر zero-width
      3) "ي"→"ی" ، "ى"→"ی" ، "ك"→"ک" ، "ﻙ"→"ک" ، "ة"→"ه" ، حذف "\u0640"
      4) حذف دیاکریتیک با _DIACRITICS.sub("")
      5) translate(_TO_LATIN_DIGITS)
      6) "\u00a0"→" " سپس re.sub(r"\s+"," ") و strip()
  قرارداد تست: normalize_persian("  ي\u200cك  ") == "یک"   [S-21]

■ to_persian_digits(value) -> str
  None → ""؛ فقط translate(_TO_PERSIAN_DIGITS). مصرف داخلی ندارد.

■ fa_money(value, currency=None) -> str

  except Exception: f"{flt(value):,.2f}"
  سپس fa_digits. ورودی None ⇒ flt(None)=0 ⇒ "۰٫۰۰". [Inference]

13.5 نوشتن merge-aware
```python
def _set_cell_value(ws, row_idx, col_idx, value):
    cell = ws.cell(row=row_idx, column=col_idx)

    if isinstance(cell, MergedCell):
        for merged_range in ws.merged_cells.ranges:
            if (
                merged_range.min_row <= row_idx <= merged_range.max_row
                and merged_range.min_col <= col_idx <= merged_range.max_col
            ):
                ws.cell(
                    row=merged_range.min_row,
                    column=merged_range.min_col,
                ).value = value
                return True

        return False

    cell.value = value
    return True
```
چرا مهم: openpyxl روی MergedCell استثنا می‌دهد؛ این تابع تنها مسیر امن نوشتن است.
